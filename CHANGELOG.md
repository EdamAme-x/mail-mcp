# Changelog

## 0.3.0 — mail-mcp

- Publish under the unscoped `mail-mcp` package name. The CLI command and `~/.mail-mcp` credential directory remain the same.
- Add Ultracite with Oxlint and Oxfmt, checked in CI alongside TypeScript and tests.
- Add contributor guidance, private security reporting, PR and issue templates, and dependency update configuration.
- Keep project documentation, comments, CLI output, and fixtures in English.

The previous `@ame-x/mail-mcp@0.3.0` release introduced typed `neverthrow` errors, partial failure reporting, token refresh recovery, and provider response limits.
